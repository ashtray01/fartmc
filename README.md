# FartMC / FartPlugin 2

Новая реализация по поведению предоставленного FartPlugin 1.2 для Paper 26.2
и 26.3, Java 25. Клиентский мод не нужен. Код: GPL-3.0-only; собственный
публичный звуковой пак: CC0-1.0. Оригинальный JAR (ARR) сохранён только локально.

## Запуск на Windows

```powershell
./scripts/build.ps1
./scripts/build-public-pack.ps1
./test-server/start.ps1 -AcceptEula -WithSounds
```

`-AcceptEula` означает принятие https://aka.ms/MinecraftEULA.
Нужен JDK 25: задайте `JAVA_HOME` или передайте `-JavaHome`.
Скрипт также обнаруживает Temurin 25 в стандартном каталоге Windows.
Maven и Paper загружаются автоматически при необходимости. Для генерации
собственных звуков установите FFmpeg в PATH или передайте его путь через
`build-public-pack.ps1 -Ffmpeg <путь>`. Сторонние записи не скачиваются.
Сервер доступен на `127.0.0.1:25565`, online-mode включён.
Подключайтесь обычным клиентом соответствующей версии с авторизованным аккаунтом.
Для реальных звуков примите предложенный сервером ресурспак.

Только smoke-test (включение плагина, загрузка мира, команды, остановка):

```powershell
./test-server/start.ps1 -AcceptEula -WithSounds -Smoke
./test-server/start.ps1 -Version 26.2 -AcceptEula -WithSounds -Smoke
```

`-Update` проверяет последнюю стабильную сборку выбранной ветки Paper;
по умолчанию уже скачанная сборка сохраняется. Её метаданные и SHA-256
лежат в `test-server/runtime-<version>/paper-build.json`.
Миры разных версий изолированы. Smoke-тесты используют отдельные
`runtime-<version>-smoke`, порт 25566 и HTTP-порт 8124, поэтому не мешают
обычному локальному серверу. Одновременно запускайте только один smoke-тест.
Скрипт каждый раз восстанавливает серверные настройки из шаблона.

## Управление

Новые пункты клавиш в меню Minecraft без мода добавить нельзя.
Комбинации используют стандартные действия и учитывают переназначенные игроком клавиши.

| По умолчанию | Действие |
| --- | --- |
| Shift + F (присесть + сменить руку) | Случайный пук; смена предметов отменяется |
| Shift + ЛКМ в воздух с обеими пустыми руками | Тихий шептун; смотрите вдаль от блоков/существ |
| Двойной Shift за 350 мс | Серия треска |
| `/fart` | Случайный профиль |
| `/fart classic/whisper/bubbles/trumpet/rattle/thunder/squeak` | Конкретный профиль (одно имя) |
| `/fart toggle` | Отключить/включить участие и слышимость |
| `/fart hotkeys` | Отключить/включить комбинации |
| `/fart auto` | Отключить/включить неожиданные события |
| `/fart help` | Памятка |
| `/fart <игрок> [стиль]` | Администратор: эффект от другого участника |
| `/fartreload` | Перечитать настройки; HTTP/ресурспак меняются после рестарта |

Личные настройки сохраняются в данных игрока. Права: `fartplugin.use`
по умолчанию всем, `fartplugin.others` и `fartplugin.reload` — операторам.
Участие отключившего эффекты игрока нельзя принудительно включить командой другого.

## Неожиданные ситуации

Сблизились до 2.3 блока — 18% вероятности тихого шептуна у одного участника.
Следующая попытка только после выхода и нового входа в ближнюю зону.
После еды — 35% вероятности отложенного эффекта через 3–8 секунд.
Приземление с уроном — 12% вероятности басового эффекта; урон не меняется.
После 30 секунд неподвижности — 1.5% вероятности писка каждые 2 секунды.
В воде случайный ручной эффект превращается в пузырьки.
Общая пауза — 4 секунды, между автоматическими эффектами — 35 секунд.
Последовательные случайные профили не повторяются.
Все вероятности и комбинации настраиваются в config.yml; `command-only`
оставляет только команды. Никакого изменения блоков, предметов или скорости игрока.

## Публичный звуковой пак и GitHub Actions

На push, pull request и ручном запуске workflow собирает и тестирует JAR,
синтезирует 7 собственных звуков, проверяет лицензии/состав архивов и сохраняет:

- `fartmc-plugin`: JAR, GPLv3, NOTICE, исходники этой сборки и SHA256SUMS.
- `fartmc-sounds`: готовый `fartmc-sounds.zip` под CC0 и SHA256SUMS.

Артефакты доступны на [странице Actions](https://github.com/ashtray01/fartmc/actions)
30 дней. Распакуйте внешний архив артефакта, чтобы получить JAR или внутренний
ресурспак ZIP. GitHub Release автоматически не создаётся.
Для дальнейшего распространения JAR сохраняйте соответствующие исходники,
LICENSE и NOTICE. Локальная подготовка пакета публикации после коммита:
`./scripts/prepare-distribution.ps1`.

Генератор `scripts/SynthesizeSounds.java` использует осцилляторы и шум,
не использует чужие записи. Результат: `dist/fartmc-sounds.zip`, моно OGG
Vorbis, встроенные CC0, SOURCES.json и SHA-256 файлов.
Пак необязателен: принявшие его слышат синтезированные пуки, отказавшиеся — композиции
из звуков Minecraft. Плагин проверяет статус загрузки отдельно для каждого игрока.
Форматы пака: 88.0–97.1 (26.2–26.3); новые версии требуют проверки.

Для обычного сервера скопируйте `target/fartplugin-2.0.0.jar` в `plugins/`,
а `dist/fartmc-sounds.zip` в `plugins/FartPlugin/resource-pack.zip`.
В `plugins/FartPlugin/config.yml` задайте публичный `resource-pack.url`;
при использовании встроенного HTTP задайте bind-адрес и откройте порт 8123.
По умолчанию HTTP слушает только loopback. Можно разместить тот же ZIP
на HTTPS-хостинге и указать его прямой URL. Сервер Minecraft не передаёт файлы
ресурспака через игровой порт.

## Локальные записи Myinstants

Ранее выбранные источники сохранены в `resource-pack/sources.json` и
`docs/SOUND_SOURCES.json`. Разрешение на перепубликацию этих записей не установлено,
поэтому CI их не скачивает и не публикует. Локальный загрузчик остался доступен
как `./scripts/build-pack.ps1 -LocalOnly`; этот параметр не предоставляет
никаких дополнительных прав. Его результат `.cache/fartmc-pack.zip`
не используется публичной сборкой. Ранее скачанные файлы сохранены локально.
Полный разбор — `docs/LICENSING.md`, уведомления — `NOTICE.md`.

Старый config.yml лучше сохранить и заменить новым: детали миграции —
`docs/REVERSE_ENGINEERING.md`. Статус проверок и работа для будущих агентов —
`docs/PLAN.md`, `docs/TESTING.md`, `AGENTS.md`.
