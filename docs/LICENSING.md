# Лицензии и состав публикации

Актуализировано 2026-10-21 для FartMC 2.1.0.

| Компонент | Условия |
| --- | --- |
| Код плагина, скрипты, тесты и документация | GPL-3.0-only, полный текст в LICENSE |
| Семь процедурных звуков | CC0-1.0, текст в licenses/CC0-1.0.txt |
| 21 запись из sounds/ | Предоставлены владельцем; заявление и SHA-256 в sounds/PROVENANCE.json, пояснение в sounds/RIGHTS.txt |
| Paper API и Adventure | Предоставляются сервером, в JAR не включаются |
| JUnit, Maven, FFmpeg, Java | Инструменты тестирования/сборки, в публикацию не включаются |

## Предоставленные записи

Владелец назвал записи royalty-free, подтвердил «файлы не требуют лицензии»
и прямо запросил сборку и публикацию проекта со звуками. Публикация этих 21 файлов
опирается на это заявление поставщика. Исходные ссылки и отдельные лицензионные
документы не предоставлены; независимая проверка происхождения не выполнена.

Обозначение `LicenseRef-User-Provided` в манифесте ссылается на эту запись
о происхождении. Это не переобъявление аудио в CC0/GPL и не утверждение о владении
правами со стороны FartMC. Исходные условия, если они существуют, сохраняются.
Имена файлов сохранены, включая имена загрузивших их авторов.

## Состав сборки

`scripts/build-public-pack.ps1` создаёт полный пак: 21 предоставленная запись
и 7 синтезированных звуков, всего 28 моно OGG Vorbis, семь профилей по четыре
варианта. Формат пака 97.1, только Minecraft 26.3.

Внутри ZIP: `SOURCES.json` с SHA-256 каждого OGG, `PROVENANCE.json` с SHA-256
исходных MP3, `LICENSE.txt`, `CC0-1.0.txt`, `NOTICE.txt`, определения профилей
и сами звуки. CC0 относится только к семи процедурным звукам.

Distribution gate допускает из аудиобинарников в Git только 21 конкретный MP3
из манифеста с совпадающими контрольными суммами. Иные MP3/OGG/WAV, JAR, ZIP,
исполняемые файлы, миры и кэши запрещены. Неодобренные локальные записи и внешний
исходный JAR не попадают в Git/CI. Историческая справка сохранена в
[REVERSE_ENGINEERING.md](REVERSE_ENGINEERING.md).

Actions создаёт два артефакта:

- `fartmc-plugin`: JAR, LICENSE, NOTICE, соответствующие исходники и SHA256SUMS.
- `fartmc-sounds`: полный `fartmc-sounds.zip` и SHA256SUMS.

Для версионных тегов проверенные файлы также публикуются в GitHub Releases:
JAR, звуковой ZIP, архив соответствующих исходников, LICENSE, NOTICE.md и SHA256SUMS.
Релиз v2.1.0 использует файлы успешного Actions run 39549156837 без пересборки.

При распространении JAR сохраняйте LICENSE/NOTICE и соответствующие исходники
именно этой сборки. Источники другой версии не заменяют их.
Тексты лицензий зависимостей и ссылки на них приведены в [NOTICE.md](../NOTICE.md).
