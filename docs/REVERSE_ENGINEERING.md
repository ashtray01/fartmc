# Исходный артефакт

FartPlugin.jar: SHA-256 `28049E33C7AF88112A8A793FA14BADD066DAE025A028287377E27C04A7520A82`.
Метод анализа: ZIP-ресурсы и javap -p -c; бинарник не запускался.
Автор в plugin.yml: Denji, версия 1.2, main com.denji.fartplugin.FartPlugin,
api-version 1.18. Встроенный pom: Java 17, Paper 1.21.4, bStats 3.0.2.

Старый код воспроизводит custom.fart_normal / custom.fart_splash при
приседании или /fart [playername]; проверяет воду в блоке игрока.
Звук получает сам игрок и окружающие в sound-radius. Есть частицы,
вероятность приседания, command-only и опциональный вертикальный толчок.
/fartreload перезагружает конфигурацию. При входе запрашивается жёстко
заданный Dropbox resource pack. Создаётся bStats с ID 25271.

Новая реализация написана заново по поведению; сохраняет имя плагина и
основные команды. Не зависит от Dropbox и не содержит телеметрии.
Старый config.yml допускается, новые параметры имеют значения по умолчанию.
Старый Dropbox URL больше не используется. resource-pack.enabled теперь
управляет локальным необязательным ZIP. sneak-fart.*, particles.type/amount/speed/offset и
fart-flying.* больше не управляют эффектами: звуки теперь vanilla или Myinstants,
одиночное приседание заменено комбинациями, физические толчки удалены.
Перед обновлением сохраните старый config.yml и используйте новый шаблон.
