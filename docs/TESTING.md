## Автоматические проверки

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -ExecutionPolicy Bypass -File scripts/test-food-server.ps1 -SkipBuild
```

| Проверка | Результат |
| --- | --- |
| Java 25, компиляция против стабильного Paper API 26.1.2 | PASS |
| 10 JUnit-тестов: звуковые профили, физика еды, здоровье, таймер, миграция идентификаторов/конфига и 20 секунд шаурмы | PASS |
| Paper 26.2 build 134, 736 серверных утверждений | PASS |
| Тот же JAR 2.3.2: запуск на Paper 26.1.2 build 74 и 26.3 build 209 | PASS |
| Команды, HTTP ZIP, штатная остановка без ошибок плагина | PASS |
| 28 звуков, шесть item_model (три новых и три старых), три объёмные модели и три текстуры, исходные хэши и структура пака | PASS |

Серверный тест проверяет регистрацию рецептов, PDC, item_model, canAlwaysEat,
остатки молочных вёдер в рецепте, отказ от модифицированных ингредиентов,
позднюю отмену потребления, запрет одновременных эффектов и сохранение кулдауна.
Для 2.3.1 добавлены новые названия, миграция старых предметов без потери количества
и модели, сохранение имени с наковальни, округление секунд, исчезновение полосы,
однократное уведомление о готовности и восстановление статуса при входе.
Проверены успешное и отменённое питьё молока, вторая рука, обычная еда без сброса,
отключение сброса настройкой и сохранение активного эффекта после молока.

В 2.3.2 дополнительно проверяются новые команды и автодополнение, PDC и item_model
`belyash`, `cheburek`, `shaurma`, распознавание/миграция старой еды, сохранение количества
и имён с наковальни, удаление старых рецептов, обновление подсказки длительности.
Модульные тесты проверяют перенос старых настроек без потери значений, приоритет
явно заданных новых параметров и увеличение старых стандартных 15 секунд до 20.
Полёт проверяется до естественного окончания: зависание, повторное поджигание после
очистки огня от старта, сохранение полёта через 16 секунд, завершение после 20 секунд.
Регрессия: собственный FIRE не считается опорой и не прерывает полёт; поверхность
под ним имеет правильную высоту, вода и лава продолжают определяться как опасные.

Также проверяются здоровье 18 → 10 → 4 → 12, низкое здоровье, смерть и повторная
остановка, сохранение чужих зелий, 600 обновлений беляша, истечение пятен без изменения
блоков, запрет/разрешение/отключение огня, препятствие для тяги и 20 одновременных сессий.
Реальная стойка с пассажиром движется через velocity и зависает в диапазоне 5–7 блоков;
остановка удаляет сиденье и передаёт посадку конечному Slow Falling.

Тест запускается только в `test-server/runtime-26.2-smoke`, на `127.0.0.1:25566`
с HTTP `127.0.0.1:8124`. Временный probe-JAR удаляется после прогона и не входит
в дистрибутив. Player в проверках — прокси над настоящей Bukkit-сущностью;
вызовы интерфейса полосы проверяются без графического клиента. Тестовый чанк
удерживается ticket, чтобы сущности обновлялись без подключённых игроков.

При локальном прогоне Paper сообщил о недоступной внешней проверке обновлений.
Это не помешало запуску, проверкам плагина, loopback HTTP и остановке с кодом 0.

Дополнительный smoke-прогон проверяет включение, готовность мира, команды,
совпадение HTTP-пака и штатную остановку на 26.1.2 и 26.3.
Полный интеграционный прогон механики еды выполняется на 26.2.

## Проверка дистрибутива

Distribution gate 2.3.2 из чистого коммита — **PASS**.
В `runtime-26.2` установлены окончательные JAR и ZIP; сервер оставлен выключенным.
Конфигурация автоматически мигрирует при следующем запуске через `start-server.bat`.
Игровой адрес `127.0.0.1:25565`, HTTP `127.0.0.1:8123`, offline-режим — по запросу владельца.

После коммита, из чистого рабочего дерева:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-public-pack.ps1
powershell -ExecutionPolicy Bypass -File scripts/prepare-distribution.ps1
```

Gate проверяет содержимое JAR/ZIP, лицензии, происхождение и точные хэши ассетов,
создаёт соответствующий исходный архив и `SHA256SUMS`. Myinstants, исходный ARR JAR,
тестовые плагины, миры и логи в публичную сборку не входят. GitHub Actions выполняет
сборку, модульные тесты и этот gate; серверный интеграционный прогон выполняется локально.

Запустить `start-server.bat`, подключиться к `127.0.0.1:25565`. Использовать двух
игроков, один принимает ресурс-пак, другой отказывается. Выдача — `/fartmc give`.
