# FartMC — план и проверки

## Версия 2.1.0 — 2026-10-21

- Единственная целевая версия: Paper/Minecraft 26.3, Java 25. Обновлены API,
  plugin.yml, запуск тестового сервера и формат всех звуковых паков: 97.1.
- Зелёное облачко появляется низко позади игрока при любом профиле. Для whisper
  оно меньше, для bubbles добавляются пузырьки. Настройка частиц, видимость,
  отказ от участия и радиус сохраняются. Общий seed синхронизирует запись у слушателей.
- Все 21 пользовательская запись включены в публичную сборку по прямому запросу
  владельца. Его заявление о правах и исходные SHA-256 сохранены в sounds/PROVENANCE.json;
  CC0 относится только к семи синтезированным звукам. Полный пак: 28 OGG, 7 профилей
  по 4 варианта. Посторонние локальные записи и бинарники исключены из CI.
- README переписан как игровая страница. Техническая установка вынесена в docs/SETUP.md.
  Пользователь решил генерировать картинки сам; три промпта и целевые пути сохранены
  в docs/IMAGE_PROMPTS.md. Предоставленная обложка docs/images/fartmc-hero.png
  просмотрена и подключена в README как иллюстрация.
- Maven clean verify с Paper API 26.3.build.207-stable: BUILD SUCCESS,
  2 теста, 0 ошибок. Полный звуковой пак собран локально.
- Smoke-test Paper 26.3 build 209: PASS, плагин включён, мир готов, команды работают,
  HTTP ZIP совпадает с собранным, сервер остановился штатно. Только loopback,
  online-mode=true. Все 28 OGG полностью декодируются: mono Vorbis 44100 Hz,
  контрольные суммы исходников/результатов совпадают, формат пака строго 97.1.

## Оставшиеся ручные проверки

- Два обычных клиента 26.3: принятие/отказ от пака, все профили и варианты,
  сочетания клавиш, слышимость, облачко стоя/присев/в воде/при взгляде вверх и вниз.
- Переключатели участия/частиц, повторный вход, права и сохранность предметов.
- Дополнительные иллюстрации whisper/bubbles можно добавить позднее по сохранённым промптам.
- Другие версии игры не заявляются поддерживаемыми без отдельной проверки.
