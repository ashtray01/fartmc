# FartMC — состояние проекта

## Обновление 2.3.2

- Команды, PDC еды, ключи рецептов и item_model переведены на `belyash`, `cheburek`, `shaurma`.
  Полные русские названия оставлены по ответу владельца.
- Старые предметы распознаются и мигрируют; старые команды остаются совместимыми псевдонимами.
  Секции конфига переносятся с сохранением настроек; явно заданные новые значения имеют приоритет.
- Пак сохраняет исходные ассеты и их хэши; добавлены три определения новых item_model.
- Шаурма действует 20 секунд. Старое стандартное значение 15 при миграции обновляется,
  остальные пользовательские длительности сохраняются; штатная подсказка предмета обновляется.
- Исправлена досрочная остановка полёта: поиск опоры пропускает FIRE/SOUL_FIRE,
  сохраняя точную высоту земли и обнаружение воды/лавы. Проверяется повторное поджигание
  во время зависания, полёт после 16 секунд и естественное завершение после 20.
- Порядок выпуска: проверка дистрибутива из чистого коммита, push, тег v2.3.2
  и автоматическая публикация GitHub Release после успешной сборки тега.

Актуальная версия: **2.3.2**, 2026-10-21. История реализации и прошлых проверок
сохранена в [HISTORY.md](HISTORY.md); текущие результаты — в [TESTING.md](TESTING.md).

## Выполнено

- Реактивная еда: три рецепта и модели, беляш с пятнами, водяная тяга, огненный
  полёт с настоящим пассажиром, безопасная очистка и необязательный ресурс-пак.
- Названия «Чебурек загадочный» и «Просроченная шаурма» сохранены. Старые
  идентификаторы распознаются для миграции; штатные имена уже выданных предметов обновляются при
  входе, открытии контейнера, подборе и перерегистрации рецептов. Имена с наковальни сохраняются.
- Полоса «Желудок ещё не готов» показывает секунды до следующего приёма еды,
  учитывая одновременно кулдаун и активный эффект. При готовности приходит уведомление.
  Сохранённый кулдаун восстанавливается при входе.
- Завершённое питьё молока сбрасывает кулдаун. Отменённое потребление не действует.
  Начавшийся эффект продолжается и не позволяет наложить второй. Возврат ведра — ванильный.
- Настройки `foods.milk-resets-cooldown` и `messages.cooldown-bar-enabled`
  включены по умолчанию; старые конфиги получают эти значения без ручной миграции.
- Исправлен повторный запуск локального сервера: блокировка запускателя и проверка
  занятого мира происходят до сборки и замены файлов. `session.lock` не удаляется.
- Инструкции установки, еды, лицензирования и проверок актуализированы; исторические
  результаты отделены от текущих. Для выпуска **v2.3.2** инструкции загрузки
  переведены на [GitHub Release](https://github.com/ashtray01/fartmc/releases/tag/v2.3.2).
  Тег запускает сборку, проверку дистрибутива и публикацию JAR, пака, исходников,
  LICENSE, NOTICE.md и SHA256SUMS. Пользователь явно запросил тег и релиз.

- Java 25 / API 26.1.2: сборка и 10 модульных тестов — PASS.
- Paper 26.2 build 134: 736 серверных проверок, команды, HTTP-пак и штатная остановка — PASS.
  Проверены миграция имён, таймер, готовность, восстановление статуса, молоко,

## Оставшиеся игровые проверки

Графический клиент ещё не использовался для нового обновления. Нужны приём пака,
вид полосы/моделей, полное поедание и возврат ведра, shift-click крафт, звук и движение
с двух клиентов, посадка/выход в воздухе, препятствия, реальные регионы WorldGuard.
Purpur и будущие версии отдельно не проверены. Подробная матрица — [TESTING.md](TESTING.md).
