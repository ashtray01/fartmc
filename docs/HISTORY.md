# FartMC — план и проверки

## Повторный запуск локального сервера — 2026-10-21

- Причина сообщения пользователя: ранее оставленный процесс Paper держал world/session.lock;
  второй запуск завершился IOException в DirectoryLock.create. Предупреждение Unsafe
  к остановке не относится. Старый процесс остановлен командой stop с сохранением миров.
- В start.ps1 добавлены эксклюзивный lock запускателя на весь срок работы и проверка
  существующего session.lock до сборки/копирования файлов. Сам session.lock не изменяется
  и не удаляется. Повторный запуск теперь сообщает, что сервер уже работает.
- PASS: launcher lock и блокировка мира; отказ не меняет JAR/server.properties.
  Реальный запуск 26.2 дошёл до Done, второй запуск отклонён до подготовки файлов.
  Штатная остановка сохранила миры; процесс завершился с кодом 0. Сервер оставлен
  выключенным, чтобы владелец мог запустить его через start-server.bat.

пак: `127.0.0.1:8124`, `online-mode=true`. Игровой клиент этот тест не запускает.

## Ручной прогон

1. На каждой из версий 26.1.2, 26.2, 26.3 подключить два клиента той же версии
   к локальному серверу (для обычного запуска нужны авторизованные аккаунты).
2. Одним принять пак, другим отказаться. Проверить семь `/fart <style>`:
   записи у первого, звуки Minecraft у второго, зелёное облачко у обоих.
3. Повторять профили с паузой: с паком доступны четыре варианта каждого.
   С одинаковым паком слушатели слышат один и тот же вариант события.
   Во время длинной записи пройти мимо второго игрока и удалиться: положение звука
   следует за источником, громкость меняется с расстоянием, запись не перезапускается.
   Проверить слышимость у самого источника. Без пака импульсы также исходят из
   движущегося игрока; их радиус считается от его текущего положения.
4. Проверить облачко позади ног: повороты, приседание, взгляд вверх/вниз,
   whisper и bubbles. В воде bubbles также создаёт пузырьки.
5. Shift+F с предметами: эффект без обмена/потери предметов, включая паузу.
   `/fart hotkeys` возвращает обычный обмен.
   Повторить `/fart` раньше секунды: «пук еще не накопился...»; через секунду — новый эффект.
6. Shift+ЛКМ в воздух с пустыми руками: шептун. Наведение на близкий блок
   или существо не должно вызывать эффект. Двойной Shift вызывает треск.
7. За радиусом 15 блоков нет звука/частиц, whisper ограничен четырьмя блоками.
8. Проверить сюрпризы после еды, приземления, простоя и при сближении.
9. `/fart auto`, `/fart toggle`, повторный вход: выбор сохраняется.
   Нельзя принудить отключившего участие игрока командой администратора.
10. `particles.enabled: false` и `/fartreload` убирают частицы, сохраняя звук.
11. Мёртвый игрок и наблюдатель не становятся источниками; проверить права.

Генерируемые для README иллюстрации не являются результатом этой проверки.
